Problèmes à traiter

Les points d’attention

  • La propriété GA4 n'apparaît que dans la configuration du conteneur GTM : son déclenchement réel n'a pas pu être confirmé depuis la page.
  • Une ancienne propriété Universal Analytics subsiste : elle ne collecte plus de données exploitables depuis 2023.
  • Aucun événement métier observé dans le dataLayer : seul le chargement de page est mesuré.
  • Le conteneur GTM-KSRKVW est mutualisé : il pilote aussi d'autres établissements de ce fichier, donc toute modification de taggage les impacte.

Plan d’action

Les prochaines étapes

  1. Priorité 1 Retirer les balises Universal Analytics pour éviter les appels inutiles et les écarts entre outils.
  2. Priorité 2 Décrire un tunnel de réservation en événements (offre consultée, panier, coordonnées, confirmation) pour identifier où les visiteurs abandonnent.
